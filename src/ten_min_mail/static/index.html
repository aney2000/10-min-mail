How do I send mail to this address?

This server only accepts mail on your machine, so the public internet cannot reach it. Send a test message with Python: 

python -c "
import smtplib
from email.message import EmailMessage
m = EmailMessage()
m['From'] = 'someone@example.org'
m['To'] = 'YOUR_ADDRESS_HERE'
m['Subject'] = 'Hello'
m.set_content('It works.')
smtplib.SMTP('localhost', 1025).send_message(m)
"
